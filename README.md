# Aplikasi Peluang Usaha PKK

Aplikasi edukasi berbasis Flutter untuk membantu siswa kelas 11 mempelajari materi "Peluang Usaha Produk Barang/Jasa" pada mata pelajaran Produk Kreatif dan Kewirausahaan (PKK).

## Fitur Utama
*   **Materi Pembelajaran:** Akses mudah ke materi dasar peluang usaha dan analisis SWOT.
*   **Contoh Usaha:** Daftar inspiratif contoh produk barang dan jasa yang relevan untuk siswa SMK/SMA.
*   **Kuis Evaluasi:** Latihan soal interaktif untuk menguji pemahaman materi.
*   **Antarmuka Responsif:** Desain yang ramah pengguna, dapat diakses dengan baik di ponsel maupun tablet.

## Cara Menjalankan Aplikasi
1.  Pastikan Flutter SDK telah terinstal di sistem Anda.
2.  Jalankan `flutter pub get` untuk mengunduh dependensi (jika ada).
3.  Jalankan aplikasi dengan perintah `flutter run`.

## Tech Stack
*   Flutter
*   Material 3 Design
